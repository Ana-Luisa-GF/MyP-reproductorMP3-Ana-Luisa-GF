# MyP-reproductorMP3-Ana-Luisa-GF
Proyecto 2 - Base de datos musical con interfaz gráfica

Nombre: Gomez Ferro Ana Luisa

Materia: Modelado y Programación

Descripción del proyecto.

Sistema que crea y manipula una base de datos musical, el cual, consta de los siguientes elementos:  
1. Una base de datos sql.  
2. Un minero que recorre un directorio y analizar archivos MP3 con etiquetas Id3v2.4 agregando la información a la base de datos.   
3. Una interfaz gráfica con la que interactua el usuario con todo el sistema.  
4. Un "compilador", que permite buscar por los distintos campos de la base de datos.
